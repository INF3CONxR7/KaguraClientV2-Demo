📖 [INSTALLATION GUIDE]

Requirements:

    A PS3 with HEN or CFW
    WinSCP / FileZilla or mmCM with USB support

📁 Where to place the files:

    Put EBOOT.BIN into your Minecraft game directory:
    Example:
    dev_hdd0/game/NPEB01899/USRDIR [Digital Version] | dev_hdd0/game/BLES01976/USRDIR [Disc Version] (Europe)
    dev_hdd0/game/NPUB31419/USRDIR [Digital Version] | dev_hdd0/game/BLUS31426/USRDIR [Disc Version] (USA)
    dev_hdd0/game/NPJB00549/USRDIR [Digital Version] (Japan)

    Put MC.sprx and the KaguraClientV2Demo folder in:
    dev_hdd0/tmp

✅ Launch Minecraft and Enjoy!

✔️ Works on all game regions.

⚠️ Recommended: Use the digital version of the game if you want use custom images (like CustomSky or Banners) to load correctly — these features are not supported on the disc version for now and set HUD to 1.

🖼️ About Custom Images

    All custom textures (like backgrounds, banners, sky, etc.) are located in the KaguraClientV2Demo folder.
    Important: Do not exceed 2280x1520 resolution for CustomSky or it will crash.
